# Salah Social

شبكة تواصل اجتماعي كاملة (واجهة + Backend + قاعدة بيانات) بدون أي مكتبات خارجية.

## التشغيل
المتطلبات: Node.js 22.13 أو أحدث.

```bash
cd salah-social
node server.js        # أو: npm start
# افتح http://localhost:3000
```

## الإعدادات (متغيرات بيئة)
| المتغير | الوصف |
|---|---|
| `PORT` | المنفذ (الافتراضي 3000) |
| `VERIFY_CODE` | كود التوثيق (يُفحص في السيرفر فقط، الافتراضي المطلوب موجود في الكود) |
| `DATA_DIR` | مجلد قاعدة البيانات والصور المرفوعة (اجعله على قرص دائم عند النشر) |
| `NODE_ENV=production` | يفعّل Secure cookies (مطلوب مع HTTPS) |
| `TRUST_PROXY=1` | عند التشغيل خلف proxy مثل Nginx/Render/Railway |

## الأمان
- كلمات المرور مشفّرة بـ scrypt مع salt، ولا تُرسل أو تُخزن في الواجهة.
- الجلسات: كوكي HttpOnly + SameSite، والتوكن يُخزن مجزّأ (SHA-256) في القاعدة.
- كود التوثيق يُقارن في السيرفر فقط مع حد للمحاولات.
- حد للمحاولات على الدخول والتسجيل، وفحص Origin، وحماية XSS (escape + CSP)، وقيود نوع وحجم الملفات (60MB).

## الهيكل
- `server.js`: API + SQLite (`data/salah.db`) + رفع الملفات + رسائل فورية عبر SSE.
- `public/index.html`: الواجهة (SPA، RTL، Mobile First، Dark/Light).

## الانتقال للإنتاج لاحقًا
- استبدل SQLite بـ PostgreSQL (الاستعلامات في `server.js` موحدة عبر `q/one/run`).
- انقل `data/uploads` إلى تخزين سحابي (S3 / R2) مع CDN.
- أضف تأكيد البريد واستعادة كلمة المرور.


## Render
المشروع يستمع على `0.0.0.0` ويستخدم `PORT` الذي يرسله Render. يوجد ملف `render.yaml` بإعدادات النشر الأساسية.
